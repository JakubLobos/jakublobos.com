## Notes for orchestrator

- **Assumption 1 (decor block): fair use.** Width 115vw, tilts −4°/+3°, the 7 px dot and 11 px padding are single-use illustration geometry of a decor component. That is exactly the rule-1 exception, and tokenising them would only add noise. Everything else (font size, leading, gap, border, colours, duration, z-index) already uses tokens. Only the section height should join the block (R1-02).
- **Assumption 2 (toggle pattern): use a constant label plus `aria-pressed`.** That pattern is what AC-3 names, and it deletes code. Please amend the task's Scope bullet ("Pause animation" / "Play animation") so it no longer implies a label swap.
- Hover-pause limited to `(hover: hover)` is a reasonable refinement of §4.7 (it avoids sticky hover after a tap). Not a deviation.
- The implementer measured AC-4 only at 1440; the reviewer covered all widths (see above).
