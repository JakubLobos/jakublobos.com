## Orchestrator questions

- **Interface.** Stub names and paths match `architecture.md` §4.2 (`DesktopNav` is not stubbed. The task list omits it, and T-023 creates it inside `Header`, so no shared file changes). Pages are one-liners. `HomePage` composition is final. Props are enough: sections get `locale`. `Header` and `MobileMenu` get `locale` + `path`. `Footer`, `CookieBanner` and `SocialAside` can derive the privacy link from `alternatePath(locale, '/privacy')`. `request<T>(path, init, guard)` → `ApiResult<T>` matches §4.4 exactly. It doesn't use `any`, narrows the envelope and `fields` explicitly, drops unknown field codes and never throws.
- **Deviation 1 (`path` prop):** accepted. It's used consistently in layout → Seo/Header/MobileMenu.
- **Deviation 2 (`.env` hand-parse):** accepted. `astro/config` exports no `loadEnv` (`defineConfig, envField, fontProviders, getViteConfig, mergeConfig, …`), and `vite` doesn't resolve from `apps/web`. `vite.envDir` alone can't cover the need, because `site` and CSP `connect-src` are needed before Vite loads env. The parser is minimal and correct for `KEY=value`: I verified CRLF, double quotes, surrounding whitespace and an ignored non-`PUBLIC_` key with a temporary root `.env` (canonical `https://example.test/pl`, `connect-src … https://api.example.test`; the file was removed afterwards). Small semantic gap in R1-02.
- **Deviation 3 (`set:html` JSON-LD):** **narrow-exception case applies.** I tried the alternatives in a temporary build (reverted). `set:text` on the script HTML-escapes the content (`{&quot;@context&quot;…`). Inside a raw-text `<script>` those entities aren't decoded, so the JSON is invalid. `<script type="application/ld+json">{personJson}</script>` is emitted literally. The current use meets the conditions. The input is build-time constants only (profile, locale, `PUBLIC_SITE_URL`). `<` is escaped to `<` (`Seo.astro:34`). The `eslint-disable-next-line astro/no-set-html-directive` states why, and the rule is active (`error`). AGENTS rule 5 and `security.md` §3 should record this single exception (see notes).
- **Deviation 4 (`showcase.astro`):** accepted.
- **Deviation 5:** `noindex` on 404s is harmless. The out-of-flow `SkipLink` is not fully harmless (R1-01).
- **T-020 follow-ups:** PASS one font preload, `Rubik Doodle Shadow` latin `unicode-range` (U+0000-00FF…). PASS `.page` computes `display: flow-root`. Pixel rows at x=800 and x=1300 at 1440×900 match `desktop-1440-hero.png` exactly (`#ececea` at y=106/212/318, `#f7f7f6` at 104/105/107/108/210/211/213/214).
