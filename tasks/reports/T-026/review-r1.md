## Contrast (orchestrator's key risk)

axe 4.14 (`/` and `/pl`, 1440 steps 1–3 and 390) reports **0 serious/critical violations, but that result is not evidence.** Every text node in `#experience` comes back as `incomplete: bgGradient`, because the page-wide background grid stops axe from computing a background. I measured the contrast on `--color-bg #f7f7f6` myself:

| Use                                      | Colour                       | Ratio (on bg / on grid line `#ececea`) |
| ---------------------------------------- | ---------------------------- | -------------------------------------- |
| meta label, 12px mono                    | violet `#7b5cff`             | 4.07 / 3.69                            |
|                                          | blue `#2e88d0`               | 3.53 / 3.20                            |
|                                          | red `#e05a6a`                | 3.35 / 3.04                            |
| inactive rail date (12px) and org (17px) | `--color-text-faint #a9a9a6` | 2.20 / 1.99                            |

Which case applies: **no approved accessible variant exists for either use.** D-01 (design-system §4) adjusts only muted, counter/placeholder, tech and tag. It keeps paint colours only for the marquee, on the grounds that the marquee is decorative and `aria-hidden`. So this is not a "raw colour used where an approved token exists" MAJOR. The implementer followed the design and the token doc, and flagged the gap honestly. D-01 also does not explicitly cover either use, though, so per NFR-02 (WCAG 2.2 AA) both are unresolved 1.4.3 failures that need an owner decision (R1-01, R1-02).
