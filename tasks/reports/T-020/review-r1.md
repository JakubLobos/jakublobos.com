## Checklist

**Requirements & design** PASS: ACs met. Tokens match §2 1:1 plus additions (R1-02). Rendering at 390/768/1024/1440 matches the design wherever this task has visible output (grid, colours, fonts).
**Correctness** PASS: Edge cases are font Unicode coverage (latin-ext verified), reduced motion, and text zoom. The showcase script has no listeners or timers.
**Architecture** PASS: Global CSS is imported once in `BaseLayout`. The wrapper is a scoped `<style>`. The dev route is isolated in an integration. Comments explain why.
**Type safety** PASS: No `any`, casts, or non-null assertions. `dataset` values are narrowed (`if (token && prop)`).
**Security & privacy** PASS: No HTML sinks. 0 `style="` attributes in dev and built HTML (the showcase sets values through the CSSOM). No `define:vars`, no inline handlers, no `PUBLIC_` additions, no raw colours outside `tokens.css` (`rg` check from design-system §3.1 is empty). The Fonts API `<style>` blocks will be hashed by `security.csp` (ADR-0012), so no CSP conflict.
**Accessibility** PASS: Focus ring, reduced motion, and forced colours verified. axe (4.11, Chrome) on the showcase at 4 widths: 0 violations. On the placeholder pages: only moderate `landmark-one-main`/`region`, because the pages have no `<main>` yet. That belongs to T-021 (chrome) and is not serious or critical.
**Responsive & performance** PASS: No horizontal scroll. Built CSS is 5.6 KB raw / 2.1 KB gzip, within the 25 KB budget. The preload weight is covered in R1-01. No JS ships in production; the showcase script is dev-only.
**Tests** PASS: `tokens.test.ts` parses `tokens.css` and asserts all colour roles, all paints and tints (with an order test), all motion tokens, and samples of type, spacing, layout, and shape. It also checks that only `:root` is declared and no `--font-*` tokens. Changing any asserted value, reordering paints, or adding a selector would fail it. It is deterministic and uses no network.
**Process** PASS: One Conventional Commit with the task ID, and only allowed files. The report has two inaccurate statements (R1-01, R1-03).
