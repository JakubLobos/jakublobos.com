## 2. OpenAI Moderation API

| Question                 | Finding                                                                                                                                                                                                                                                                                                                                                                             | Source                                                                                                                                                                                                 |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Capability               | `POST /v1/moderations`, model `omni-moderation-latest`, text + image input; response `flagged`, `categories`, `category_scores` (0–1), `category_applied_input_types`; 13 categories (harassment, harassment/threatening, hate, hate/threatening, illicit, illicit/violent, self-harm, self-harm/intent, self-harm/instructions, sexual, sexual/minors, violence, violence/graphic) | [Moderation guide](https://developers.openai.com/api/docs/guides/moderation)                                                                                                                           |
| **Pricing**              | "The moderation endpoint is free to use". The pricing page lists "Moderation \| omni-moderation-latest \| Free". _Free today; could change, so the design caps usage._                                                                                                                                                                                                              | guide; [Pricing](https://developers.openai.com/api/docs/pricing)                                                                                                                                       |
| **Account requirements** | API key from an OpenAI platform account (the guide's examples use `OPENAI_API_KEY`). The Free usage tier requires the user to be "in an allowed geography" (monthly usage limit $100); paid tiers start at $5 of credit purchases. The guide doesn't state whether a payment method is required to call the free endpoint. **Verify at account setup.**                             | [Rate limits](https://developers.openai.com/api/docs/guides/rate-limits)                                                                                                                               |
| Rate limits              | No moderation-specific limits published. 429 responses may include `Retry-After`; `x-ratelimit-*` headers exist.                                                                                                                                                                                                                                                                    | rate-limits guide                                                                                                                                                                                      |
| Data handling            | `/v1/moderations`: abuse-monitoring retention **None**, application state **None**, ZDR-eligible, **not used for training**. EU data residency requires approval and is for eligible accounts.                                                                                                                                                                                      | [Your data](https://developers.openai.com/api/docs/guides/your-data)                                                                                                                                   |
| Caveats                  | "Treat moderation scores as signals for your application's policy, not as an automatic blocking decision." The model is "continuously upgraded", so thresholds may need recalibration. Not for CSAM detection. Profanity isn't a category.                                                                                                                                          | guide                                                                                                                                                                                                  |
| Multilingual             | The guide is silent. OpenAI's 2024 announcement: the omni model is more accurate especially in non-English languages (+42 % on a 40-language internal eval). An independent benchmark shows multilingual recall still much lower than English.                                                                                                                                      | [Announcement](https://openai.com/index/upgrading-the-moderation-api-with-our-new-multimodal-moderation-model/), [Portkey benchmark](https://portkey.ai/blog/openai-omni-moderation-latest-benchmark/) |

**Conclusion:** suitable as the primary classifier for a low-volume public guestbook. It's free, fast, retains no data, and is purpose-built. It must be complemented by local rules (links, contact info, profanity/PL terms), a fail-closed policy, and a takedown path (ADR-0005).

## 4. Node.js runtime facts

- `node:sqlite` in Node 24: **Stability 1.2 – Release candidate**, no flag needed, synchronous API, no transaction helper ([docs](https://nodejs.org/docs/latest-v24.x/api/sqlite.html)). Not chosen (ADR-0004).
- Native TypeScript type stripping works in Node 24.20 for a pnpm workspace importing `.ts` source from another workspace package (local prototype, no warnings). See ADR-0009.

## 5. SEO and locale redirects

Google: "Avoid automatically redirecting users from one language version of a site to a different language version"; Googlebot usually crawls without `Accept-Language`. Recommends separate URLs per language, hreflang, and visible links between versions ([Google Search Central](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites)). Our mitigations are in ADR-0007.
